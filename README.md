# PCC — обновления для Windows

Этот каталог содержит версии, описания изменений, установщики PCC и необходимые
лицензионные материалы WiX. Отдельного исходного архива PCC и данных проектов здесь
нет. Установщик содержит рабочий код Python, сборочные исходники и тесты PCC;
этот состав опубликован с разрешения владельца.

Выпуски: https://github.com/Ksarno/PCC-updates/releases

С исправленной версии 1.0.5 PCC проверяет `latest.json` при запуске. Если доступно обновление,
показывает версию, изменения и кнопку «Обновить». Загрузка и запуск происходят
после нажатия; контрольная сумма установщика проверяется перед запуском.
Проекты обновляются отдельно в менеджере PCC.

В 1.0.4 проверка недоступна из-за ошибки встроенного Python. Перейдите на
1.0.7 один раз вручную, запустив новый установщик поверх существующей версии.

Подпись **PCC TEST ONLY** — тестовая, без публичного доверия издателя. Windows
может показать предупреждение или заблокировать установку. Не отключайте защиту
Windows и не добавляйте сертификат в доверенные корневые для обычного использования.

Обычное удаление PCC сохраняет список проектов и резервные копии Legacy.
Дополнительная галочка полного удаления очищает эти локальные данные после
подтверждения. Папки проектов сохраняются всегда.

Изменённая тема установщика и лицензии находятся в `wix-materials/`;
полный исходный архив соответствующего WiX сопровождает релиз.
